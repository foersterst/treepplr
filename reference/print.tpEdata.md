# Print the expected input of a TreePPL model

Console method for objects returned by
[`tp_expected_input()`](http://treeppl.org/treepplr/reference/tp_expected_input.md).
It shows the model file, the model name and one line per argument, in
green, with the R object to supply in brackets.

## Usage

``` r
# S3 method for class 'tpEdata'
print(x, ...)
```

## Arguments

- x:

  An object of class `tpEdata`.

- ...:

  Not used; present for compatibility with
  [`print()`](https://rdrr.io/r/base/print.html).

## Value

`x`, invisibly.
