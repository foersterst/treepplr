# Open a directory in the system's file browser

Open a directory in the system's file browser

## Usage

``` r
tp_open_dir(dir = tp_tempdir())
```

## Arguments

- dir:

  Path to a directory. Defaults to
  [`tp_tempdir()`](http://treeppl.org/treepplr/reference/tp_tempdir.md).

## Value

`dir`, invisibly.
