# Print a TreePPL sampler

Console method for objects returned by
[`tp_sampler()`](http://treeppl.org/treepplr/reference/tp_sampler.md).
It shows the path to the compiled executable, the model file, the
inference method and, if any, the compile options.

## Usage

``` r
# S3 method for class 'tpSampler'
print(x, ...)
```

## Arguments

- x:

  An object of class `tpSampler`.

- ...:

  Not used; present for compatibility with
  [`print()`](https://rdrr.io/r/base/print.html).

## Value

`x`, invisibly.
