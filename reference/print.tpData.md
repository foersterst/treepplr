# Print the JSON input of a TreePPL model

Console method for objects returned by
[`tp_data()`](http://treeppl.org/treepplr/reference/tp_data.md). It
shows the path to the JSON file, the model name and the arguments
written to the file, with the R object each one was built from.

## Usage

``` r
# S3 method for class 'tpData'
print(x, ...)
```

## Arguments

- x:

  An object of class `tpData`.

- ...:

  Not used; present for compatibility with
  [`print()`](https://rdrr.io/r/base/print.html).

## Value

`x`, invisibly.
